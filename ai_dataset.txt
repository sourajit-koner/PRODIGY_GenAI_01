Responsible AI development considers technical performance as well as social consequences.
Machine learning is a branch of artificial intelligence that learns patterns from data.
A machine learning model uses examples to learn relationships between inputs and outputs.
Training is the process of adjusting a model so that it performs better on available data.
Supervised learning uses examples that include known target values or labels.
Unsupervised learning looks for useful structures in data without predefined labels.
Reinforcement learning allows an agent to learn through rewards and penalties.
Classification models predict categories such as spam or not spam.
Regression models predict numerical values such as prices or temperatures.
Clustering algorithms group data points according to similarities.
Features are measurable properties that are provided to a machine learning model.
Labels represent the expected answer in a supervised learning dataset.
A training dataset is used to fit the parameters of a machine learning model.
A validation dataset can help select models and tune their settings.
A test dataset is used to estimate how well a trained model generalizes.
Overfitting occurs when a model learns training details too closely and performs poorly on new data.
Underfitting occurs when a model is too simple to capture important patterns.
Regularization can help reduce overfitting in some machine learning models.
Cross-validation can provide a more reliable estimate of model performance.
Feature scaling is useful for algorithms that are sensitive to the magnitude of input features.
Machine learning workflows often include data preparation, training, evaluation, and deployment.
Deep learning is a specialized area of machine learning based on multi-layer neural networks.
Deep neural networks can learn multiple levels of representation from raw or processed data.
Neural network layers transform input information into increasingly useful representations.
Deep learning has achieved strong results in image, speech, language, and video applications.
Training deep networks can require substantial computational resources.
Graphics processing units can accelerate many deep learning operations.
An activation function introduces nonlinear behavior into a neural network.
ReLU is a commonly used activation function in deep neural networks.
Backpropagation is used to calculate gradients during neural network training.
Gradient-based optimization updates model parameters to reduce a chosen loss function.
Dropout can reduce overfitting by temporarily disabling parts of a neural network during training.
Batch normalization can help stabilize and accelerate some neural network training processes.
Convolutional neural networks are especially useful for many image-processing tasks.
Recurrent neural networks were designed to process sequential information.
Transformers have become highly influential in modern language and multimodal AI.
Deep learning models often improve when trained with larger and more diverse datasets.
Model checkpoints can be saved during training so that progress can be recovered.
Learning rate is an important training parameter that controls the size of optimization updates.
Epochs represent passes through a training dataset during model training.
Deep learning requires careful evaluation because high training accuracy does not guarantee generalization.
Natural language processing allows computers to work with human language.
NLP is used for text classification, translation, summarization, and information extraction.
Tokenization divides text into smaller units that a language model can process.
Words, subwords, or characters can be used as tokens depending on the system.
Text preprocessing may include normalization, cleaning, and removal of unwanted characters.
Sentiment analysis attempts to identify opinions or emotional tone in text.
Named entity recognition identifies items such as people, organizations, and locations.
Machine translation converts text from one language into another.
Text summarization produces a shorter representation of a longer document.
Question answering systems generate answers from questions and available information.
Language models learn statistical or neural patterns in sequences of text.
Embeddings represent words, sentences, or documents as numerical vectors.
Semantic similarity compares text based on meaning rather than only exact word matches.
Search engines can use language understanding to improve the relevance of results.
Speech recognition converts spoken language into written text.
Text generation models can produce new passages based on prompts or previous context.
NLP systems can struggle with ambiguity, slang, sarcasm, and context-dependent language.
Multilingual NLP aims to build language technology that works across many languages.
Prompt design can influence the quality and relevance of responses from language models.
Evaluation of NLP systems should consider both accuracy and the quality of generated language.
Computer vision enables computers to analyze and interpret visual information.
Images can be represented as arrays of numerical pixel values.
Image classification assigns an image to one or more predefined categories.
Object detection identifies objects and estimates their locations within an image.
Image segmentation assigns labels to individual pixels or regions.
Face detection locates faces in images or video frames.
Optical character recognition converts text appearing in images into machine-readable text.
Convolutional neural networks are widely used for visual recognition tasks.
Data augmentation can create modified training examples from existing images.
Common image augmentations include cropping, rotation, scaling, and flipping.
Computer vision can support quality inspection in manufacturing environments.
Medical image analysis can assist professionals with tasks involving scans and images.
Autonomous vehicles use computer vision to understand parts of their surroundings.
Video analysis applies visual processing to sequences of frames over time.
Image embeddings can represent visual content in a numerical feature space.
Vision models can be trained to recognize objects, scenes, or visual patterns.
Lighting and camera conditions can affect the performance of a computer vision model.
Computer vision systems should be tested across diverse environments and populations.
Visual data often requires careful labeling before it can be used for supervised learning.
Computer vision is an important component of many modern robotics systems.

Large language models are a major technology behind many text-generation applications.
Image generation models can create pictures from natural language descriptions.

A prompt is an instruction or input that guides a generative AI system.
Prompt engineering focuses on designing clear and useful instructions for AI models.
Generative AI can help developers draft documentation and prototype applications.
AI assistants can summarize documents and explain technical concepts.
Code generation tools can help programmers write or modify software.
Generative AI can support brainstorming by producing multiple possible ideas.
Generated content should be reviewed because AI systems can produce inaccurate information.
Hallucination describes cases where a generative model produces unsupported or incorrect information.
Retrieval-augmented generation can provide a model with relevant external information at generation time.
Fine-tuning can adapt a pretrained model to a specific task or domain.
Generative AI can be integrated into chatbots and customer support applications.
Creative professionals can use generative tools for early-stage ideation and prototyping.
AI-generated content may require human review before being published or used professionally.
Generative AI systems can respond differently to prompts that contain different levels of detail.
Responsible use of generative AI includes checking facts, privacy, copyright, and safety considerations.
