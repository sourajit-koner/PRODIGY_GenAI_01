# Prodigy InfoTech - Task 01

## Text Generation with GPT-2

This project was developed as part of the Prodigy InfoTech Generative AI Internship.

### Objective

The objective of this project is to fine-tune a pretrained GPT-2 transformer model on a custom dataset and generate coherent and contextually relevant text based on a given prompt.

### Technologies Used

- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- GPT-2

### Dataset

A custom Artificial Intelligence text dataset was created and used to fine-tune the GPT-2 model.

### Project Workflow

1. Created a custom AI dataset
2. Loaded the dataset
3. Loaded pretrained GPT-2
4. Tokenized the dataset
5. Prepared the data using a data collator
6. Fine-tuned GPT-2
7. Saved the trained model
8. Generated text using custom prompts
9. Tested the model with multiple prompts

### Example Prompt

Artificial intelligence

### Example Output

The fine-tuned GPT-2 model generated AI-related text based on the provided prompt.

### Result

The model successfully generated coherent text related to the topics present in the training dataset.

### Conclusion

This project demonstrates how a pretrained GPT-2 transformer model can be fine-tuned on a custom dataset for text generation.
